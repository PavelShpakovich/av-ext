# Chrome Web Store Listing

## Основное название

AV.BY Цены в долларах

Альтернативные варианты:

- AV.BY Цены в долларах
- AV.BY Конвертер BYN в USD
- AV.BY USD Helper

## Короткое описание

Показывает цены в долларах рядом с суммами в BYN на av.by по курсу НБРБ или выбранного банка.

## Полное описание

AV.BY Конвертер цен в USD добавляет примерные цены в долларах рядом с суммами в BYN на страницах объявлений и автомобилей на av.by.

Расширение подходит тем, кто привык оценивать стоимость авто в долларах и хочет видеть пересчёт прямо на странице без калькулятора.

Возможности:

- Конвертирует цены из BYN в USD прямо на страницах av.by.
- Поддерживает официальный курс НБРБ.
- Поддерживает курс продажи выбранного банка с Myfin.
- Обновляет курсы автоматически при запуске расширения и каждые 10 минут.
- Работает с динамически обновляемыми страницами av.by.
- Хранит только локальные настройки и кэш курсов в браузере.

Как это работает:

- Расширение находит цены в BYN на страницах av.by.
- Получает курсы валют из НБРБ и, при необходимости, курсы банков с Myfin.
- Показывает рядом с исходной ценой примерное значение в USD.

Примечания:

- Цена в USD является приблизительной и зависит от выбранного источника курса.
- Банковские курсы зависят от текущей структуры сайта Myfin.
- Расширение работает только на страницах av.by.

## Single Purpose Description

Это расширение конвертирует цены в BYN в примерные значения в USD на страницах av.by по курсу НБРБ или выбранного банка.

## Обоснование разрешений

### storage

Используется для сохранения локальных настроек пользователя, выбранного источника курса, выбранного банка, настройки округления и кэша курсов в браузере.

### tabs

Используется для уведомления открытых вкладок av.by об изменении настроек или курса, чтобы цены на странице обновлялись автоматически.

### alarms

Используется для автоматического обновления курсов в фоне каждые 10 минут.

### host permission: https://_.av.by/_

Используется для чтения цен на страницах av.by и отображения рядом с ними примерной суммы в USD.

### host permission: https://api.nbrb.by/*

Используется для получения официального курса USD из НБРБ.

### host permission: https://myfin.by/*

Используется для получения курсов продажи USD у банков, если пользователь выбирает банковский источник курса.
